# SHORTCUTS.md — full keyboard map

| Action | Shortcut | Notes |
| --- | --- | --- |
| New todo / focus quick add | Ctrl+N | focuses active pane's quick-add |
| Create todo | Enter (in quick add) | stays focused, clears input |
| Create + open details | Shift+Enter (in quick add) | |
| Global quick add | Ctrl+Shift+Space | OS-global; tiny floating window, default target Inbox |
| New list | Ctrl+Shift+N | created + inline rename armed |
| Switch list / commands | Ctrl+K | fuzzy palette: lists, layouts, views, theme |
| Switch to list 1–9 | Ctrl+1 … Ctrl+9 | rail order; shown in rail + Go menu |
| Filter current list | Ctrl+F | toggles filter bar; live, fuzzy, accent-insensitive |
| Global search | Ctrl+Shift+F | all lists; breadcrumbs; Enter jumps to todo |
| Navigate todos | ↑ / ↓ | visible rows of active pane |
| Open details | Double-click / Shift+Enter | |
| Toggle Done | Ctrl+Enter | on selected todo |
| Pin / unpin to list | Ctrl+P | selected todo |
| Rename selected | F2 | focuses + selects detail title |
| Move up one level | Alt+← | selected todo, out of its group |
| Delete (to Trash) | Delete | soft delete + undo toast |
| Undo | Ctrl+Z | app-wide, snapshot stack |
| Todo text size | Ctrl+MouseWheel | 10–20px; also A−/A+ in scale popover |
| Keyboard shortcuts help | F1 | dialog; also Help menu |
| Close popup / panel | Esc | priority: menu → dialogs → overlays → rename → picker → filter → detail |

Menu bar (File · Edit · View · Go · Help) mirrors every shortcut with its hint text — it is the discoverability surface. In production also support Alt-key menu accelerators per Windows convention.
